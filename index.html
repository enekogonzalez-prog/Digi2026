Digi2026

Este es el repositorio de github el cual se va a usar para Digi2026 en el 1er año de Dam.

Estructura del Proyecto

Para mantener el trabajo ordenado durante el curso, dividimos el contenido en varios repositorios:

  • digi2026-landing: Esta página web de presentación.
  • dam-java-logic: Prácticas y código de programación en Java.
  • linux-bash-wargames: Prácticas de terminal y comandos en Linux.
  • ciber-sc900-notes: Apuntes y preparación para la certificación SC-900.

Organización y Rutina

El proyecto también documenta la planificación diaria: levantarse temprano, entrenar en el gimnasio, asistir a las clases en SEIM por la mañana y dedicar las tardes al estudio técnico y a los idiomas.
